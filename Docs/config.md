**編譯期與全域預設**
- `N_AXIS=3`：軸數 3–8；>3 需支援的 driver/board map。
- `AXIS_REMAP_ABC2UVW=Off`：在 4–6 軸時可將 ABC 改為 UVW。
- `N_SPINDLE=1`、`N_SYS_SPINDLE=1`：可用主軸數與同時啟用主軸數。
- `PLANNER_ADD_MOTION_MODE=Off`：planner 是否記錄 motion mode。
- `BUILD_INFO="E2D-Strom_DLC32_V2P1"`：`$I` 資訊字串。
- `COMPATIBILITY_LEVEL=0`：Grbl 1.1 相容層級。
- `ENABLE_SPINDLE_LINEARIZATION=0`、`SPINDLE_NPWM_PIECES=4`：主軸線性化。
- `KINEMATICS_API`：目前未啟用（註解）。
- `MASLOW_ROUTER/WALL_PLOTTER/DELTA_ROBOT/POLAR_ROBOT=Off`：特殊運動學關閉。
- `MINIMUM_FEED_RATE`：若 `DELTA_ROBOT=On` 則 `0.1f`，否則 `1.0f`。

**實驗/進階功能**

**檔內自動修正/檢查**
- `N_TOOLS` 上限 32；`N_SYS_SPINDLE` 會被限制到 1–8 且不大於 `N_SPINDLE`
- `NGC_EXPRESSIONS_ENABLE` 開啟時保證 `NGC_PARAMETERS_ENABLE=On`
- WCO/Override 的 refresh count 範圍檢查
- `DEFAULT_LASER_MODE` 與 `DEFAULT_LATHE_MODE` 不可同時開啟
- `LATHE_UVW_OPTION` 與 `AXIS_REMAP_ABC2UVW` 不可同時開啟
- 多個 `*_MASK` 為負值時會改為全軸/全訊號
- `DEFAULT_SPINDLE_ON_DELAY` 與 `DEFAULT_COOLANT_ON_DELAY` 若非 0，會限制到 500–20000 ms
- Parking 與 `DEFAULT_HOMING_FORCE_SET_ORIGIN` 不可同時啟用

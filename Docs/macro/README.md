# P900.macro 說明與使用方式

本檔案僅保留 `P900.macro` 的用途與操作方式。

## 功能

`P900.macro` 用於在執行 `$RST=*` 後，重新建立必要的預設座標：

- 設定 G28 位置為 `X-117.0 Y-196.0 Z-2.0`
- 設定 G30 位置為 `X-234.0 Y-196.0 Z-2.0`
- 設定 G59.3 偏移為 `X-50.0 Y-5.0 Z-20.0`

## 檔案位置

- `docs/macro/P900.macro`

請將 `P900.macro` 複製到控制器 SD 卡的 macro 目錄。

## 使用方式

### 手動執行

在控制器端執行：

```gcode
G65 P900
```

### 自動執行（開機/重啟後）

設定 startup line：

```gcode
$N0=G65 P900
```

注意：`$RST=*` 會清除 startup line，請在重置後重新設定。
補充：在控制器端送出 `$N0=G65 P900` 後，該設定會寫入控制器的 startup line 初始值；重啟後會自動執行。

#### 避開 `$RST=*` 清除 startup line

`$RST=*` 會重置所有設定，包含 startup line。若只是要清除座標或部分設定，請改用較小範圍的重置指令：

- 只清座標：`$RST=#`
- 只清機台設定：`$RST=$`

這樣可避免清掉 `$N0/$N1`。若仍需要執行 `$RST=*`，建議保留一份 startup line 設定值，重置後立刻再寫回（例如重新下 `$N0=G65 P900`）。

## 注意事項

- `P900.macro` 內含 `G53` 位置移動，請先完成 homing。
- 確認安全高度與行程範圍，避免碰撞。
- 本 macro 為 ASCII-only。

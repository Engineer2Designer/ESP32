# $# (NGC 參數) 回報格式

本文件說明 grblHAL 在送出 `$#` 指令時的回報格式與各欄位意義，對應 `main/grbl/report.c` 的 `report_ngc_parameters()`。

## 概述

`$#` 會輸出下列資訊：
- 工作座標系 (G54~G59.3) 偏移
- G28/G30 預設位置
- G92 暫時偏移
- 工具表 (Tool Table) 資料
- HOME、TLO、PRB（以及可能的 TLR）
- 若啟用縮放，包含 G51 縮放參數

座標數值輸出單位依 `settings.flags.report_inches` 決定（公制/英制）。

## 輸出順序與格式

### 1) 縮放 (若啟用)
```
[G51:X,Y,Z]
```
- 代表目前縮放比例 (G51)。

### 2) 工作座標系與固定點
```
[G54:X,Y,Z]
[G55:X,Y,Z]
[G56:X,Y,Z]
[G57:X,Y,Z]
[G58:X,Y,Z]
[G59:X,Y,Z]
[G59.1:X,Y,Z]
[G59.2:X,Y,Z]
[G59.3:X,Y,Z]
[G28:X,Y,Z]
[G30:X,Y,Z]
[G92:X,Y,Z]
```
- G54~G59.3：WCS 偏移 (持久化)
- G28/G30：預設回原點位置 (持久化)
- G92：暫時偏移 (非持久化)

### 3) 工具表 (Tool Table)
```
[T:tool_id|X,Y,Z|radius|6,0,0|name|pocket]
```
欄位說明：
- `tool_id`：刀號
- `X,Y,Z`：工具補償/偏移 (由 tool_data->offset.values 輸出)
- `radius`：工具半徑或補償值
- `6,0,0`：保留/擴充欄位
- `name`：工具名稱 (可空) 
- `pocket`：夾頭穴/刀庫位置 (可空)

> 備註：僅輸出 `tool_id` 合格的刀具。條件依 `settings.macro_atc_flags.random_toolchanger` 不同而異。

補充說明：
- `tool_id` 一般由 `Tn` 選刀指令使用；是否輸出 `T0` 取決於 random toolchanger 設定。
- `X,Y,Z` 與 `radius` 為 Tool Table 的持久化補償資料，重啟後仍保留。
- `6,0,0` 目前為固定保留欄位，供未來擴充使用。
- `name`/`pocket` 來自工具表的擴充欄位；若控制器或介面未提供設定能力，可能保持空白或預設值。

如何設置（Tool Table）：
- 以 `G10 L1` 直接寫入指定刀號的補償資料，例如：
  - `G10 L1 P1 Z12.5`（寫入 T1 的 Z 偏移）
  - `G10 L1 P2 X0 Y0 Z0 R1.5`（寫入 T2 的 XYZ 偏移與半徑）
- 以 `G10 L10/L11` 由量測結果計算寫入（常用於量測後快速記錄）。
- 寫入後用 `$#` 檢查輸出是否更新。
- 詳細語法與差異請參考 `docs/G10.md`。

### 4) HOME
```
[HOME:X,Y,Z:mask]
```
- `mask` 為已回原點軸遮罩 (bitmask)。例：`7` 表示 XYZ 都已 homed。
  - 以位元代表各軸是否完成 homing，bit=1 表示該軸已回原點。
  - 位元對應順序依軸索引排列，最低位為 X，其次為 Y，再來為 Z；若有 A/B/C 等延伸軸則依序往高位排列。
  - 例：`1`=僅 X 已 homed，`3`=X/Y 已 homed，`5`=X/Z 已 homed，`7`=X/Y/Z 已 homed。

### 5) TLO
```
[TLO:value]
```
- 目前刀長補正值。

### 6) PRB
```
[PRB:X,Y,Z:0|1]
```
- 探針位置與成功旗標 (`1` 成功, `0` 失敗/未觸發)。

### 7) TLR (若存在)
```
[TLR:value]
```
- 工具長度參考偏移 (非持久化)。只有 `sys.tlo_reference_set` 為真時輸出。

## 參考輸出範例
```
[G54:-185.000,-145.000,-40.000]
[G55:-100.000,-50.000,-50.000]
[G56:-100.000,-50.000,-50.000]
[G57:-185.000,-145.000,0.000]
[G58:0.000,0.000,0.000]
[G59:0.000,0.000,0.000]
[G59.1:0.000,0.000,0.000]
[G59.2:0.000,0.000,0.000]
[G59.3:0.000,0.000,0.000]
[G28:0.000,0.000,0.000]
[G30:0.000,0.000,0.000]
[G92:0.000,0.000,0.000]
[T:1|0.000,0.000,0.000|0.000|6,0,0||1]
[T:2|0.000,0.000,0.000|0.000|6,0,0||2]
[T:3|0.000,0.000,-1.000|0.000|6,0,0||3]
[HOME:0.000,0.000,0.000:7]
[TLO:0.000]
[PRB:0.000,0.000,0.000:0]
```

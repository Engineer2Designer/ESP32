# GRBLHAL E2D ATC

## 範圍（Scope）

- 適用於 grblHAL Plugin `e2d_atc` 程式碼、ATC 宏/腳本，以及定義換刀行為的相關文件。
- 若任務與 ATC、換刀、或 `e2d_atc` 用法無關，則不適用（可略過本技能）。

## 工作流程（撰寫 / 實作）

1. 確認目標行為：一般換刀（normal tool change）或僅卸刀（T0 unload-only）；自動量刀（auto-measure）開/關（$454）。
2. Pocket 一律使用機械座標：`$456` 的座標為 **G53**，不得與工作座標（G54+）混用。
3. 強制安全條件：停主軸（M5）、關冷卻（M9），且僅允許在 **IDLE** 狀態進行換刀。
4. 及早驗證參數：tool id、pocket 是否存在、進給/轉速範圍、移動距離（尤其 Z 安全高度與相容性）。
5. 一致處理刀長：若啟用自動量刀，則透過 T0（或定義的量刀流程）進行探測；否則套用 tool table 的 offset。
6. 結束時恢復狀態：座標系、冷卻、主軸，以及目前刀號（M61 Qn）。Z 行為需符合「Z 回位契約」。

## 工作流程（審查 / Review）

- 座標使用：pocket 移動必須用 **G53**；動作規劃不得混用工作/機械座標。
- 狀態守門：換刀流程必須拒絕非 **IDLE** 狀態（例如 Cycle、Hold、Alarm、移動中）。
- 運動順序：先抬到 `$458` 安全高度 → XY → 目標 Z；回位行為需與文件一致（回 XYZ）。
- 錯誤處理：出錯時確保主軸停止；軟限位（soft limits）恢復；pending 狀態清除。
- 記錄/訊息：避免緊迴圈刷屏；延遲與 timeout 設計一致且有上限。
- 宏呼叫：M6/T 用法必須顯式；不得依賴不安全預設或隱藏狀態。

## G65（僅在使用宏時適用）

- 一致使用命名/區域變數；清楚文件化必要參數與預設值。
- 驗證所有參數：必須為數值、範圍正確、符號/正負符合預期；缺少必要參數必須拒絕。
- 返回前恢復所有 modal 變更（例如 G90/G91、G54/G53、feed/spindle）。

## 參數驗證規則（Baseline）

- tool_id：0..31；且 `$456` 必須同時具備目前刀與目標刀的 pocket entry（依流程需要）。
- $450..$458：必須強制落在文件規範的 min/max 範圍內。
- $458：必須 >= 當前 Z 與目標 Z，否則視為錯誤並中止。
- Z 移動距離：必須為正值；進給（feed）必須 > 0。
- 探針目標：不得超出機械 Z 限位；探測失敗必須立刻停止並回報錯誤。

## 設定表（$450..$458）

| Setting | 意義 | Min | Max | 備註 |
| --- | --- | --- | --- | --- |
| $450 | ATC spindle RPM | 1000 | 3000 | 換刀時主軸轉速 |
| $451 | ATC Z feed rate | 100 | 1000 | Z 軸進給（mm/min） |
| $452 | ATC spindle stop delay | 0.5 | 5.0 | 主軸停轉延遲（秒） |
| $453 | ATC Z move distance | 5.0 | 50.0 | Z 下移距離（mm） |
| $454 | ATC enable measurement | 0 | 1 | 自動量刀開關 |
| $455 | ATC measure feed rate | 50 | 500 | 探測進給（mm/min） |
| $456 | ATC tool pockets | - | - | 格式：`Tn X Y Z`（G53 機械座標） |
| $457 | ATC XY feed rate | 100 | 2000 | XY 進給（mm/min） |
| $458 | ATC safe Z (G53) | -5.0 | 0.0 | 安全高度（G53，必定先抬到此高度） |

## Z 回位契約（精確描述）

- 一般換刀（T1+）：返回原 **XYZ**（先抬到 `$458` → 回 XY → 下 Z）。
- T0 卸刀：返回原 **XYZ**（同上）。
- `$458` 為強制安全高度，必須高於當前/目標 Z；若不符則應報錯並中止。

## 提交前檢查清單（Pre-Commit Checklist）

- README 與程式碼對換刀步驟與 Z/XY 回位行為一致。
- 已文件化 `$456` 格式與 **G53** 強制要求。
- T0 卸刀路徑與一般換刀路徑在錯誤情境下皆能安全處理。
- 已驗證狀態恢復：soft limits、座標系、冷卻、主軸。
- 無新增無上限迴圈；timeout 仍一致且有上限。
